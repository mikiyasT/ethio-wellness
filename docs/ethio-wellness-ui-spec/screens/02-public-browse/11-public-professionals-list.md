# Professionals list (`public-professionals-list`)

- **Purpose:** Filterable directory of professionals — the core discovery surface; fully usable by guests.
- **Who can see it:** All.
- **Layout regions:** Guest header · page head · persistent left filter sidebar (desktop) · results grid · "show more" · footer · mobile filters bottom sheet (overlay).
- **Visible UI elements:** Title "Find your counselor" + guest reassurance line; desktop left sidebar (~300px) — name search field; language chip group (All, አማርኛ, ትግርኛ, Afaan Oromoo, English); specialty chip group (8 starter); availability chip group (Any time, Today, This week); "Sort by" select (Soonest available / Highest rated); "Clear all filters" text action; mobile toolbar row with "⚙ Filters" button and sort select; result count; professional cards — avatar initials, name, title, city, rating, **language tags**, specialties, next-open slot, View profile button.
- **Mobile filters bottom sheet:** Tapping "Filters" opens a sheet that slides up from the bottom of the screen over a dimmed page. Sheet contents — drag handle; "Filters" title + ✕ close button; "Specialty" multi-select chip section (8 starter categories); "Language" multi-select chip section (All, አማርኛ, ትግርኛ, Afaan Oromoo, English); "Sort by" section (Soonest available / Highest rated); sticky footer with primary "Show N results" button (N = live count of matching professionals) and "Clear all" text action. The sheet is scrollable internally and never taller than ~85% of the viewport.
- **Primary action:** "View profile" → `public-professional-detail` for that professional.
- **Secondary actions:** Desktop sidebar chips toggle filters inline (multi-select within language/specialty, single within availability); sidebar search filters by name; sidebar sort select reorders; "Clear all filters" resets every section to its default. On mobile, the toolbar keeps search + sort visible; tapping "Filters" opens the bottom sheet where selections are staged — nothing applies until "Show N results" is tapped; tapping ✕, the drag handle area, or the dimmed backdrop dismisses the sheet without applying; "Clear all" resets every section to its default. The sidebar sort select and the sheet's "Sort by" section stay in sync. "Show more professionals" paginates.
- **Navigation:** Header as on `welcome-home`. Card → `public-professional-detail`. A category arriving from `public-browse-services` pre-selects that specialty filter (visible as an active chip in the sheet / desktop sidebar group).
- **Fields:** Required vs optional — all filters optional.
- **Validation messages:** None.
- **Variants:** Empty — `states/11-public-professionals-list-empty` ("No matches found / Try a different name, specialty, or language." + Clear filters). Loading — skeleton cards (documented, frame optional in v1). Filters sheet open — `11-public-professionals-list-mobile-filtersheet.png` (mobile only; sheet over dimmed list, Couples + አማርኛ selected in the mock).
- **Responsive notes:** Desktop — persistent left filter sidebar (~300px) beside the 3-col results grid; the sidebar holds the name search, language/specialty/availability chip groups, the sort select, and "Clear all filters". Mobile — one-column result list; the sidebar collapses into the "Filters" button in the toolbar; tapping it opens the bottom sheet with the same filter functionality (specialty, language, sort); all sheet controls keep ≥44px tap targets; search and sort stay visible in the toolbar without opening the sheet.
- **Localization notes:** Language chips show native script (አማርኛ wider than "EN") — chips must size to content; professional cards must not truncate language tag lists — wrap to two lines. Sheet title, section labels, "Show N results", and "Clear all" need translation per locale; the N in "Show N results" stays numeric in all locales.
